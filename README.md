# Personal Portfolio

A responsive personal portfolio website showcasing my skills, projects, and experience as a Systems Development graduate.

**Live Website:** [njabulo.dev](https://njabulo.dev)

## About the Project

This portfolio is a personal website designed to introduce me as a developer and provide an overview of the work I have created.

The project started as a portfolio built while following a tutorial. I am gradually rebuilding and improving it so that the code, structure, and design reflect what I have learned rather than simply following someone else's implementation.

The current focus is on keeping the website:

* Simple
* Professional
* Responsive
* Easy to understand
* Easy to maintain
* Built with technologies I understand

## Features

The portfolio currently includes:

* Responsive navigation
* Hero section introducing me and my work
* Skills section with interactive skill categories
* Projects section showcasing completed work
* Responsive project cards
* Links to project repositories and live projects
* Mobile-first responsive design
* Custom styling using CSS
* JavaScript interactions for selected sections

## Design

The portfolio follows a minimal visual style using a limited colour palette.

The primary colours are:

* White
* Black
* Blue
* Blue variations used for accents and supporting UI elements

The design intentionally avoids unnecessary colours and visual elements so that the content remains the main focus.

### Responsive Design

The website is developed using a **mobile-first approach**.

The layout starts with a smaller-screen design and progressively adapts to larger screen sizes using CSS media queries.

Major responsive changes include:

* Mobile navigation layout
* Hero section adjustments
* Skills interface layout changes
* Project card layout
* Desktop project grid/row layout

## Development Approach

This portfolio is also a learning project.

Rather than attempting to build everything at once, I am improving the website section by section.

The development process generally follows:

```text
Plan
  ↓
Build HTML structure
  ↓
Style with CSS
  ↓
Make responsive
  ↓
Add JavaScript where appropriate
  ↓
Test
  ↓
Refactor
  ↓
Document
```

A major goal of the project is understanding **why** the code works instead of simply making the website work.
